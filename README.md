# ☕ Java Study Challenges

Repositório dedicado à minha jornada de aprendizado em **Java**, com exercícios práticos, desafios de lógica e pequenos projetos desenvolvidos ao longo dos estudos.

O objetivo não é apenas resolver exercícios, mas **entender como o código funciona, praticar a resolução de problemas e evoluir continuamente como desenvolvedor**.

## 🎯 Objetivos

- Fortalecer a lógica de programação.
- Compreender os fundamentos da linguagem Java.
- Praticar estruturas condicionais e de repetição.
- Aprender a organizar e documentar código.
- Desenvolver pequenos projetos de forma gradual.

## 🧠 Método de aprendizado

Para cada desafio, busco:

1. Entender o problema.
2. Planejar uma solução.
3. Escrever o código.
4. Testar diferentes situações.
5. Revisar o resultado e explicar como funciona.
